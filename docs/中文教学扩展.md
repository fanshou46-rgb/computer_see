# 中文教学扩展架构

本地扩展基于 PC Anatomy，保留上游探索、对比、模型构建与 MIT 许可证。课程入口为 `app/learning-app.tsx`，原探索入口 `app/page.tsx` 通过动态导入按需加载，两种模式不同时挂载。

## 数据和状态

- `lib/learning-courses.ts`：十章课程、四类知识小游戏、局部拆装与整机挑战。局部拆装和整机挑战构成另外两类游戏。
- `lib/learning-rules.ts`：纯函数状态机。`installed`、`fixed`、`locked`、`connected` 分别记录就位、固定、锁扣与接线；按钮和拖拽均调用 `applyAction`。错误操作返回原状态。
- `lib/learning-progress.ts`：浏览器本地存档，schema 版本 1。保存章节、当前步骤、题目位置、组装状态和已完成拆卸目标。坏存档尽可能保留连续完成章节，并重置当前练习。
- `lib/learning-scene.ts`：独立课程场景。复用台式机与内存几何，另行创建 Latitude 5440 参考教学笔记本。机型切换时销毁当前场景，不缓存第二套课程模型。

`buildModel` 新增可选的 `preserveAssemblies` 参数，默认 false，保持原探索模型的合并策略。课程构建台式机时仅保留主板内可操作装配的子部件，显卡仍按总成合并；独立 CPU、内存、SSD 姿态不由原拆解时间轴驱动。

## 中文内容

`lib/chinese.ts` 提供中文术语和按功能结构编写的中文教学解读。`Concept.english` 保留原始英文名称、说明和用途，原文可从详情折叠区查阅。原英文名称加入搜索词，中英文检索均可用。规格字段和引用保留上游资料。

层级编号、分类键和原始分支标签仍然稳定，界面显示时再翻译，防止本地化改变导航语义。`scripts/localize-interface.mjs` 是维护界面文案的工具，不在用户启动时执行。

## 判定和提示

所有状态变更先经过规则验证。观察展开、镜头变化和示范不更新真实组装状态。三级提示最后一步对副本执行单次正确操作，短暂展示后还原；用户仍需自己操作。

笔记本内部操作检查电池隔离；排线必须打开锁扣后才能断开，连接后重新锁定。整机启动先检查硬件，再检查教学 NVMe 启动盘，最后要求本关全部固定与连接完成后才可通关。

## 验证与本地运行

`tests/learning.test.ts` 验证规则与恢复；`scripts/learning-smoke.mjs` 通过公开界面完成十章课程，包含真实鼠标拖拽；`scripts/learning-performance.mjs` 测量独立浏览器进程组内存、旋转渲染率与反复切换资源数量。

`scripts/serve-local.mjs` 使用 Node 内置 HTTP 服务提供 `dist`，仅监听 127.0.0.1，无运行时 npm 依赖。默认端口 4173，通过“启动电脑实验室.cmd”打开。
